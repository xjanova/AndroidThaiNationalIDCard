# คู่มือการใช้งานระบบแก้ไขข้อมูลบัตรประชาชน
## สำหรับเจ้าหน้าที่ราชการเท่านั้น

---

## ⚠️ คำเตือนสำคัญ

ระบบนี้พัฒนาขึ้นเพื่อใช้ในงานราชการเท่านั้น การใช้งานต้อง:
- ได้รับอนุญาตจากหน่วยงานที่เกี่ยวข้อง
- มี Admin PIN ที่ถูกต้อง (8 หลัก)
- ระบุเหตุผลในการแก้ไขทุกครั้ง
- ระบบจะบันทึก Audit Log ทุกการแก้ไข

**การใช้งานโดยไม่ได้รับอนุญาตถือเป็นความผิดทางกฎหมาย**

---

## การเข้าถึงระบบแก้ไขข้อมูล

### 1. เปิดหน้าต่างแก้ไขข้อมูล

1. เปิดโปรแกรม Thai ID Card Reader
2. คลิกปุ่ม **"แก้ไขข้อมูลบัตร (เจ้าหน้าที่)"** หรือเมนู **"เครื่องมือ > แก้ไขข้อมูลบัตร"**
3. ระบบจะแสดงหน้าต่างยืนยันสิทธิ์:
   ```
   ⚠️ หน้าต่างนี้สำหรับเจ้าหน้าที่ราชการเท่านั้น

   การแก้ไขข้อมูลบัตรประชาชนต้องได้รับอนุญาตจากหน่วยงานที่เกี่ยวข้อง
   ต้องมี Admin PIN และระบุเหตุผลในการแก้ไขทุกครั้ง
   ระบบจะบันทึก Audit Log ทุกการแก้ไข

   คุณมีอำนาจในการแก้ไขข้อมูลหรือไม่?
   ```
4. คลิก **"Yes"** เพื่อยืนยันสิทธิ์

### 2. เลือกเครื่องอ่านบัตรและโหลดข้อมูล

1. เลือกเครื่องอ่านบัตรจาก Dropdown
2. คลิกปุ่ม **"โหลดข้อมูลจากบัตร"**
3. ระบบจะอ่านข้อมูลปัจจุบันจากบัตรและแสดงในฟอร์ม

---

## การแก้ไขข้อมูล

### ข้อมูลที่สามารถแก้ไขได้:

#### 1. **ชื่อ-นามสกุล**
- ชื่อ-นามสกุล (ไทย): สูงสุด 100 ตัวอักษร
- ชื่อ-นามสกุล (อังกฤษ): สูงสุด 100 ตัวอักษร

#### 2. **ที่อยู่**
- ที่อยู่ปัจจุบัน: สูงสุด 160 ตัวอักษร
- รองรับภาษาไทยด้วยการเข้ารหัส TIS-620

#### 3. **วันที่ออกบัตรและหมดอายุ**
- วันออกบัตร: รูปแบบ dd/MM/yyyy
- วันหมดอายุ: รูปแบบ dd/MM/yyyy หรือ "LIFETIME"

#### 4. **รูปภาพ**
- รองรับไฟล์: .jpg, .jpeg, .png, .bmp
- ขนาดแนะนำ: 240 x 320 pixels
- ขนาดไฟล์สูงสุด: ตามที่บัตรรองรับ

---

## ขั้นตอนการแก้ไขและบันทึกข้อมูล

### ขั้นตอนที่ 1: แก้ไขข้อมูลในฟอร์ม

1. **แก้ไขชื่อ-นามสกุล**:
   - กรอกชื่อใหม่ในช่อง "ชื่อ-นามสกุล (ไทย)"
   - กรอกชื่อใหม่ในช่อง "ชื่อ-นามสกุล (อังกฤษ)"
   - คลิกปุ่ม **"อัปเดตชื่อ"**

2. **แก้ไขที่อยู่**:
   - กรอกที่อยู่ใหม่ในช่อง "ที่อยู่ปัจจุบัน"
   - คลิกปุ่ม **"อัปเดตที่อยู่"**

3. **แก้ไขวันที่**:
   - กรอกวันออกบัตรใหม่
   - กรอกวันหมดอายุใหม่
   - คลิกปุ่ม **"อัปเดตวันที่"**

4. **แก้ไขรูปภาพ**:
   - คลิกปุ่ม **"เลือกรูปภาพ"**
   - เลือกไฟล์รูปภาพจากเครื่อง
   - คลิกปุ่ม **"อัปเดตรูปภาพ"**

### ขั้นตอนที่ 2: ยืนยันตัวตนก่อนบันทึก

เมื่อคลิกปุ่มอัปเดตใดๆ ระบบจะแสดงหน้าต่างยืนยันตัวตน:

```
┌─────────────────────────────────────────┐
│ ยืนยันตัวตนก่อนดำเนินการ              │
├─────────────────────────────────────────┤
│ รหัสเจ้าหน้าที่: [____________]        │
│ Admin PIN (8 หลัก): [____________]     │
│ เหตุผล: [_________________________]    │
│                                         │
│ [ยืนยัน]  [ยกเลิก]                     │
└─────────────────────────────────────────┘
```

**กรอกข้อมูล:**
1. **รหัสเจ้าหน้าที่**: รหัสประจำตัวของคุณ (เช่น "EMP001")
2. **Admin PIN**: รหัส PIN 8 หลักของผู้ดูแลระบบ
3. **เหตุผล**: เหตุผลในการแก้ไข (เช่น "แก้ไขที่อยู่ตามคำขอของเจ้าของบัตร")
4. คลิก **"ยืนยัน"** เพื่อดำเนินการ

### ขั้นตอนที่ 3: ตรวจสอบผลลัพธ์

ระบบจะแสดงผลลัพธ์:
- ✅ **สำเร็จ**: "การอัปเดต[ชื่อฟิลด์]สำเร็จ"
- ❌ **ล้มเหลว**: แสดงข้อความข้อผิดพลาด เช่น:
  - "Admin PIN ไม่ถูกต้อง"
  - "ไม่พบเครื่องอ่านบัตร"
  - "ไม่สามารถเขียนข้อมูลได้"

---

## Admin PIN

### ข้อมูลเกี่ยวกับ Admin PIN:
- **ความยาว**: 8 หลัก (ตัวเลข)
- **การยืนยันตัวตน**: ใช้ PIN Reference 0x01 (แตกต่างจาก User PIN ที่ใช้ 0x00)
- **ความปลอดภัย**: Admin PIN ควรเก็บรักษาไว้อย่างปลอดภัย และเปลี่ยนเป็นระยะ
- **การล็อก**: ระวังการใส่ PIN ผิดหลายครั้ง อาจทำให้บัตรถูกล็อก

### วิธีการเปลี่ยน Admin PIN:
(ต้องดำเนินการผ่านระบบของหน่วยงานที่ออกบัตร)

## Audit Log (บันทึกการตรวจสอบ)

### ข้อมูลที่บันทึก:
ทุกการแก้ไขจะถูกบันทึกใน Audit Log ที่:
```
C:\Users\[Username]\Documents\ThaiIDCardReader\AuditLog.txt
```

### รูปแบบการบันทึก:
```
[2024-01-15 14:30:25] UpdateAddress | AdminID: EMP001 | CardID: 1234567890123 | Status: Success
[2024-01-15 14:32:10] UpdatePhoto | AdminID: EMP001 | CardID: 1234567890123 | Status: Failed - Invalid PIN
```

### ข้อมูลในแต่ละบรรทัด:
- **วันเวลา**: เวลาที่ดำเนินการ
- **ประเภทการแก้ไข**: UpdateAddress, UpdatePhoto, UpdateDates, UpdateName
- **รหัสเจ้าหน้าที่**: รหัสของผู้ดำเนินการ
- **หมายเลขบัตร**: เลขบัตรประชาชนที่ถูกแก้ไข
- **สถานะ**: Success หรือ Failed พร้อมเหตุผล

### การตรวจสอบ Log:
1. เปิดไฟล์ AuditLog.txt ด้วย Notepad หรือโปรแกรมอ่านข้อความ
2. ตรวจสอบประวัติการแก้ไขทั้งหมด
3. **ห้ามลบหรือแก้ไข** ไฟล์ Log โดยเด็ดขาด

## การจัดการข้อผิดพลาด

### ปัญหาที่พบบ่อย:

#### 1. "ไม่พบเครื่องอ่านบัตร"
- ตรวจสอบการเชื่อมต่อเครื่องอ่านบัตร
- ลองถอดและเสียบเครื่องอ่านบัตรใหม่
- ตรวจสอบ Driver เครื่องอ่านบัตร

#### 2. "ไม่พบบัตร"
- ตรวจสอบว่าใส่บัตรเข้าเครื่องอ่านแล้ว
- ตรวจสอบทิศทางการใส่บัตร
- ทำความสะอาดชิปบัตร

#### 3. "Admin PIN ไม่ถูกต้อง"
- ตรวจสอบความถูกต้องของ PIN (8 หลัก)
- ระวังการใส่ PIN ผิดหลายครั้ง
- ติดต่อผู้ดูแลระบบหากลืม PIN

#### 4. "ไม่สามารถเขียนข้อมูลได้"
- บัตรบางรุ่นอาจไม่รองรับการเขียนข้อมูล
- ตรวจสอบสิทธิ์การเข้าถึงบัตร
- ลองอ่านบัตรใหม่และทำการแก้ไขอีกครั้ง

#### 5. "ข้อมูลเกินขนาดที่กำหนด"
- ที่อยู่เกิน 160 ตัวอักษร → ย่อให้สั้นลง
- รูปภาพเกินขนาด → ใช้รูปขนาดเล็กลง
- ชื่อเกิน 100 ตัวอักษร → ตัดให้สั้นลง

## ข้อควรระวัง

### ⚠️ ข้อปฏิบัติสำคัญ:

1. **ตรวจสอบข้อมูลก่อนบันทึก**
   - ตรวจสอบความถูกต้องของข้อมูลก่อนคลิกอัปเดต
   - ข้อมูลที่บันทึกแล้วไม่สามารถย้อนกลับได้

2. **เก็บรักษา Admin PIN**
   - ห้ามแชร์ Admin PIN กับบุคคลอื่น
   - เก็บ PIN ไว้ในที่ปลอดภัย
   - เปลี่ยน PIN เป็นระยะ

3. **ระบุเหตุผลที่ชัดเจน**
   - เหตุผลจะถูกบันทึกใน Log
   - ใช้ภาษาที่เข้าใจง่าย เช่น "แก้ไขที่อยู่ตามคำร้อง เลขที่ 123/2567"

4. **ตรวจสอบ Audit Log**
   - ตรวจสอบ Log เป็นประจำ
   - รายงานการใช้งานที่ผิดปกติ

5. **สำรองข้อมูล**
   - สำรองข้อมูลบัตรก่อนแก้ไข (Export to Excel)
   - เก็บรูปถ่ายหน้าจอไว้เป็นหลักฐาน

## ข้อกำหนดทางเทคนิค

### ระบบที่รองรับ:
- Windows 11 (แนะนำ)
- Windows 10 version 1809 ขึ้นไป
- .NET 8.0 Runtime

### เครื่องอ่านบัตรที่รองรับ:
- เครื่องอ่านบัตรมาตรฐาน PC/SC compliant
- รองรับโปรโตคอล ISO-7816

### การเข้ารหัส:
- ภาษาไทย: TIS-620 encoding
- Admin PIN: 3DES + SHA-1

## การรายงานปัญหา

หากพบปัญหาในการใช้งาน:

1. **บันทึกข้อมูลที่เกี่ยวข้อง**:
   - ข้อความ Error ที่แสดง
   - หมายเลขบัตรที่มีปัญหา (ปกปิดบางส่วนเพื่อความปลอดภัย)
   - ขั้นตอนที่ทำก่อนเกิดปัญหา

2. **ตรวจสอบ Audit Log**:
   - ดูรายละเอียดใน AuditLog.txt

3. **ติดต่อผู้ดูแลระบบ**:
   - แจ้งปัญหาพร้อมหลักฐาน
   - อย่าพยายามแก้ไขด้วยตัวเอง

## ข้อจำกัดความรับผิดชอบ

ซอฟต์แวร์นี้พัฒนาขึ้นเพื่อใช้ในงานราชการที่ได้รับอนุญาตเท่านั้น ผู้พัฒนาและผู้แจกจ่าย:
- ไม่รับผิดชอบต่อการใช้งานที่ไม่ได้รับอนุญาต
- ไม่รับผิดชอบต่อความเสียหายที่เกิดจากการใช้งาน
- ไม่รับผิดชอบต่อข้อมูลที่ถูกแก้ไขผิดพลาด

ผู้ใช้งานมีหน้าที่:
- ใช้งานภายใต้กฎหมายและระเบียบที่เกี่ยวข้อง
- รับผิดชอบต่อการแก้ไขข้อมูลทั้งหมด
- เก็บรักษาความลับของข้อมูลส่วนบุคคล
